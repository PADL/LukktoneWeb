Router One

About

A networked audio media bridge. AES67 to AES67, AES67 to AVB/Milan.

Networks
AES67, Milan
Sample rates
48 / 96 kHz
Form factor
1RU

Platforms

One software stack that scales from a Raspberry Pi to custom FPGA hardware.

Compact

Raspberry Pi

Small, low-cost bridges for compact systems.

High throughput

Software bridge

A standard server with a high-speed network adapter, such as Intel E835, for large stream counts at higher latency.

Low latency

Custom FPGA

Dedicated FPGA I/O for the lowest latency, with MADI and word clock.

Specifications

Audio networking
  • 16 input and 16 output streams per port, of up to 32 channels each (hardware dependent)
  • AES67-2023, multicast and unicast, with optional SRP reservation (AES67 Annex C)
  • Milan/AVB, with CRF media clock streams
  • Dante devices in AES67 mode†
  • Profiles: SMPTE ST 2110-30 with the ST 2059-2 PTP profile, and IPMX (VSF TR-10-1) audio
Clocking
  • Support for multiple clock domains
  • Clock conversion from and to CRF, IPMX, PTP and word clock, in any combination
  • Credit-based shaper and launch time support, where available in hardware
Routing
  • Stream-based routing
  • High quality synchronous sample rate conversion
  • Sine, square, pink noise, white noise and impulse test signals
  • WAV file playback
  • Peak level and clip metering
Control
  • Remote control over AES70, including AES70-21 connection management
  • NMOS IS-04 discovery and registration, IS-05 connection management and IS-12 control
  • ATDECC support for Milan and IEEE 1722.1 controllers, over Ethernet or WebSockets
  • Web interface served by the device
  • Command-line tool for diagnostics
FPGA hardware*
